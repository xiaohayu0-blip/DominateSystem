# 已知限制与真实接入条件

## Demo可用范围

核心网页流程已由后端与浏览器测试验证，参见verification。所有制度为合成，模型和邮件为模拟；没有把模拟成功标为真实发信或真实业务正确。正式知识库尚未提供。

当前检索使用中文字词、关键词和字符哈希向量，无外部向量模型；它适合小规模演示，不具备预训练语义召回能力。同义表只有固定代码配置，没有后台维护界面。分句主要识别问号、分号、换行和部分连接词，复杂多事项、否定和条件可能识别不完整。

模拟模型选择实际检索片段，服务端展示原文，不能代替真实生成模型验收。DeepSeek也采用证据筛选/摘录方式，未实现长篇综合回答。引用校验只验证来源ID与逐字摘录，不证明来源足够、相关或答案逻辑正确。资料中的恶意指令通过受限输出协议与服务器校验降低影响，不承诺完全消除提示注入或模型错误。

冲突检查是保守的数量/权限规则，可能误报、漏报；复杂法规优先级和例外需人工核定。历史年度默认以年末判断有效期，不支持“历史某一天”查询；当前年度按当天日期判断。多轮只承接明确前一问题的年度/年级，未实现开放式对话记忆；追问宜重复具体事项。

生命危险检测器为可审查规则，测试覆盖有限，不能代表危机识别准确率。未实现训练模型、全面语境推断或专业值守；不保证及时识别、投递或收件人阅读。当前界面可看事件、失败、重试和待发送数量，但没有独立worker心跳或外部监控告警。

SMTP存在发送后进程崩溃的不确定窗口，系统转人工核对而不是盲目重发。数据库幂等和固定Message-ID不等于端到端exactly-once。QQ收到与人工已阅读必须另验。

普通用户未核验身份，无法证明是手机号本人，存在自报冒用风险。当前以浏览器随机会话隔离数据，不开放同号跨设备恢复。会话被盗仍可能泄露该会话资料，正式运行必须HTTPS并明确学校接受的登记风险。

目前列表适用于小规模学院演示，尚未分页或进行大规模压测。API内存限流、并发信号量和每日模型请求数检查只适用单API进程；每日上限按问题记录计数，不是精确计费或token账本。生产放大规模前需补共享配额和服务预算。

OCR适配已实现，默认关闭。需安装Poppler、Tesseract和中文语言包；本次未运行真实OCR，识别质量仅提示需人工校对，没有量化评分。

## 已实现但等待外部条件验证

| 项目 | 需要提供 | 验证内容 |
|---|---|---|
| 正式知识库 | 制度原文件、单位/版本、入学年级、业务年度、有效期、代表题与负责人答案 | 导入核对，至少首批10—20题逐条人工核查 |
| DeepSeek | 服务端API Key、可用模型名称、预算 | 真实成功、超时、错误、引用及费用监控；本次只MockTransport测试 |
| SMTP/QQ | SMTP服务器、账号、授权码、发件人、指定QQ收件人、明确外发授权 | 人工授权后测试接收；不要在聊天、源码或前端填写秘密 |
| 手机与微信 | 可达地址、Android/iOS、微信 | 键盘、返回、长表单、文件打开和后台处理真机验证 |
| 正式服务器 | Linux单机、Docker/Compose、域名、HTTPS、备份位置、管理员和预警值守负责人 | 容器启动、PG迁移/恢复、TLS、安全访问、日志与监控 |

## 尚未实现

可编辑同义词管理、自动相似候选、复杂条件推理、精确模型预算账本、外部监控、列表分页与大规模检索优化。预警删除按用户要求不实施。学校统一身份认证、短信、家长学生绑定、自动审批和周报邮件属于明确排除范围。

## 留存与权限的后续决定

资料、问答、问题和人工处置长期保存。7天清理只显示候选，未启用任何删除动作。后续如要真正清理，需重新确认范围、审计和备份流程。无跨设备敏感资料恢复，若未来提出该需求，必须先解决免验证进入与身份确认的冲突。
