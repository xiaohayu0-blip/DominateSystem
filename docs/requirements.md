# 最新业务需求与实现对应

2026-11-06，用户最新提示词优先。源业务文档只作参考，旧工程与旧报告未作为实现依据。所有工程位于全新 `dominate-system-new/`。

## 已明确替换的旧规则

| 旧文档内容 | 本工程规则 |
|---|---|
| 在旧代码底座改造、沿用旧依赖与测试 | 完全从零实现，不复制任何旧代码、环境、密钥、数据库或报告 |
| 同号复用账号、查找已有资料 | 每次新登记创建独立自报资料；只在持有随机cookie的同一会话内访问当前资料 |
| 家长关联学生、选择当前孩子、切换上下文 | 家长填写多个孩子条目；没有学生ID关系、绑定表或切换孩子身份功能 |
| 30天删除 | 资料、问答、问题与处理历史长期保存，无30天清理 |
| 预警成功7天后自动清理 | 用户在本次对话明确选择仅预览，实际删除未启用且无删除接口 |
| 必须复用本地BGE | 新设计使用轻量字符向量与关键词；不下载/复制旧模型，不声称具备BGE语义检索效果 |
| 周报邮件 | 仅后台周报，根本不创建周报邮件任务 |

## 实现位置与验证层次

| 需求 | 实现 | 当前证据/边界 |
|---|---|---|
| 手机号11位无密码、无短信、自报身份 | schemas、register、RegistrationForm | 格式验证、同号隔离、无手机号查档案测试 |
| 学生姓名、手机号、专业、班级 | registrations | 持久化、字段验证和浏览器登记 |
| 家长本人及多个孩子 | child_entries、家长表单 | 双孩子、同号无绑定、无权限增加、修改与历史快照测试 |
| 管理员独立认证/退出 | security、admin API | 散列、会话撤销、越权测试 |
| 四格式资料解析和定位 | storage、chunks | PDF/DOCX/XLSX/CSV实际生成文件解析测试；页/段/表/工作表/行定位 |
| 扫描PDF OCR | 外部pdftoppm+tesseract适配 | 未安装依赖未验收；关闭时明确失败，不能发布不完整扫描件 |
| 业务年度/入学年级/有效期 | metadata、context、retrieval | 分离过滤和澄清测试；历史按年末评估，见限制 |
| 关键词与向量 | HybridRetriever | 字符哈希向量，不等同预训练语义模型；通用词和具体事项回归 |
| 模拟模型及DeepSeek | qa | 模拟按真实检索原文回答；DeepSeek只做MockTransport适配测试，真实调用待密钥 |
| 引用校验、防编造链接 | citation、服务端摘录验证 | 引用ID与逐字摘录验证，错误依据不展示；仍需人工判断相关性 |
| 多事项/无依据/冲突/澄清/系统故障 | qa、issues | 原因分别归集；澄清成功只关闭同会话明确前题的澄清事项 |
| 问答、人员、历史长期保存 | questions、issues、snapshots | 无自动删库，资料修改不追溯改写快照 |
| 问题合并与明细保留 | merge、issue_data | 两人原始记录保留，跨年度禁止合并 |
| 周报后台、北京时间、积压 | weekly | 周边界测试；本周组数与旧周积压分离，不重复计算根组 |
| 上传→发布→复测→完成 | admin documents/issues | API测试+手机浏览器全流程 |
| 版本、停用、重建索引 | documents、chunks | 已发布不可直接修改元数据；新上传为独立版本；停用不改历史引用 |
| 原文件与权限 | LocalFileStore、file API | 路径边界、下载鉴权、上传限制测试 |
| 正式答复 | formal API与表单 | 确认人、日期、依据必填，草稿发布后检索，备注不入库 |
| 紧急事件不等待模型 | submit事务→事件+任务 | 模型前事件已持久化测试，用户即时提示 |
| 邮件持久化、恢复、重试、幂等 | alerts worker | 模拟失败重试/租约恢复、重复请求、新危险内容及不确定SMTP保护测试 |
| 人工处置与邮件分离 | events、mail_jobs | 浏览器与后端均验证发信成功仍待处置 |
| 一周留存 | retention-preview | 只预览，不删除，包括未处置事件保持原样 |
| 手机与桌面网站 | React/CSS | Chromium 320/360/390/430/768/1280宽度及390核心流程；不等同真机 |
| 微信内置浏览器 | 标准响应式网站 | 待真机验证，不宣称已验收 |
| 独立演示初始化 | cli demo-init | 仅demo/mock/mock且库非空拒绝覆盖；随机演示密码不入库外明文源码 |
| 配置/审计 | settings与audit后台 | 不回传密钥；公共模式接口只返回通道名称 |
| 迁移与备份恢复 | Alembic、backup.py | 真实记录见verification，PostgreSQL容器运行另验 |

## 非首期范围
