# 面向全校学生的制度服务网站视觉调整

依据：用户要求使用ui-ux-pro-max，正式、留白充足、不要绿色或AI模板感。

## 方向与实施

采用高校公共服务门户风格：白底、墨蓝文字与主操作、浅灰分区；取消绿色、装饰渐变、宣传口号、英文装饰标签、巨幅欢迎标语和倾斜插画。选择“正式、清楚、留有余量”，不采用活泼教育产品配色或强调科技感的聊天机器人外观。

首页由学院标识区、导航、页面说明、登记表和服务说明组成。以“制度问答与问题处理”“登记咨询信息”直接命名业务。用户端与后台采用统一色彩、边框、间距和表单规范；资料来源、风险提示和演示标记仍明确展示。

## 设计系统

- 主色 ink #243A5A；正文 #252D39；次级文字 #606C7C；白色 #FFFFFF；页面浅灰 #F7F8FA；分隔线 #DEE3EB。成功状态使用蓝色，警告棕色，紧急/错误深红色，不使用绿色。
- 间距采用4/8/12/16/24/32/48/64/80px；桌面正文最大1200px，页面外侧48px起，手机20px；表单24—28px纵向间隔。
- 标题32/26/22px，正文16px，辅助信息13—14px，行高1.7；说明正文限制合理行长。默认中文无衬线“苹方/微软雅黑/Noto Sans CJK SC”，可选“思源宋体标题+黑体正文”或“系统无衬线”作为后续学校品牌匹配方案，本版统一中文黑体。
- 主按钮墨蓝底白字，触控至少44px，输入框50px；边角4—8px，不用胶囊控件或重阴影。
- 所有字段显式label关联，焦点轮廓可见；错误、空态、加载与无权限保持可理解，颜色外配文字。仅保留必要反馈，遵循prefers-reduced-motion。

参考技能内Government/Public Service配色及ux-guidelines的对比度、44px触控、表单标签、键盘焦点、正文行长要求，按用户品牌约束覆盖生成器的通用建议。

## 修改文件

web/src/main.tsx（公共框架、首页、问答/后台文案）、web/src/style.css（整体重写）、web/index.html（主题色）、web/tests/demo.spec.ts（标题定位和视觉截图）。不改业务接口、数据或权限。

## 验证

重跑类型检查、ESLint、生产构建及已有4项浏览器流程；查看首页、问答、后台和手机截图，检查320—1280宽度、键盘焦点和关键文字对比度。记录真实结果，不把响应式模拟当作微信真机验收。
